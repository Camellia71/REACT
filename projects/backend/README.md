# Backend Project

Node.js + Express + TypeScript 服务器环境

## 安装依赖

```bash
npm install
```

## 启动开发服务器

```bash
npm run dev
```

或使用自动重启模式

```bash
npm run dev:watch
```

## 构建生产版本

```bash
npm run build
```

## 启动生产服务器

```bash
npm start
```

## 环境变量

创建 `.env` 文件:

```
PORT=5000
NODE_ENV=development
```
